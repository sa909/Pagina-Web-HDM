tema: revista digital para estar al dia con la tecnologia sin aburrirse

Primero creamos una carpeta para guardar todos los archivos.

index.html: para crear la estructura y agregar los títulos y textos.
style.css: para darle diseño a la página y cambiar el color de fondo.
script.js: para agregar una función sencilla con javascript.


1. Primero hicimos la estructura básica de la página con HTML. 
2. Agregamos los títulos y textos.
3. Creamos el archivo CSS y cambié el color de fondo.
4. Creé el archivo javascript.
   
5. Agregamos un botón a la página con javascript. para que al hacer click aparezca un mensaje.
   El código que utilicé para el botón fue:

<button id="boton">Haz clic aquí</button>
<script src="script.js"></script>

6. Finalmente probamos la página para comprobar que todo funcionara correctamente.
